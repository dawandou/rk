# 第09章 项目范围管理

## 本章概览

本章介绍项目范围管理的概念、WBS分解方法以及范围控制的流程。

**重点知识点：**
- 范围管理的内容
- WBS分解原则
- 范围基准的组成
- 范围控制方法

---

## 9.1 范围规划

### 定义

范围规划是指确定项目范围并制定范围管理计划的过程。

### 主要内容

- 范围定义
- 范围管理计划
- 需求管理计划

### 关键考点

- 范围规划的输出
- 范围管理计划的内容

### 记忆口诀

范围规划定边界，管理计划来指导

---

## 9.2 WBS分解

### 定义

WBS（工作分解结构）是将项目可交付成果和工作分解成较小、更易于管理的组成部分的过程。

### 分解原则

- 完整性
- 层次性
- 可管理性
- 独立性

### 关键考点

- WBS的定义和作用
- WBS分解的原则

### 记忆口诀

工作分解结构清，层层分解到活动

---

## 9.3 范围控制

### 定义

范围控制是指监控项目范围变化，管理范围变更的过程。

### 控制方法

- 范围基准比较
- 变更控制流程
- 范围验证

### 关键考点

- 范围控制的方法
- 范围蔓延的预防

### 记忆口诀

范围控制防蔓延，变更流程要严格
