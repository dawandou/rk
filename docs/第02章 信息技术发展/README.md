# 第02章 信息技术发展

## 本章概览

本章介绍信息技术的发展历程、新技术趋势以及信息化标准规范。

**重点知识点：**
- 信息技术发展历程
- 新技术（云计算、大数据、人工智能）
- 信息化标准体系
- 信息安全技术

---

## 2.1 信息技术概述

### 定义

信息技术是指用于管理和处理信息所采用的各种技术的总称。

### 发展阶段

1. **第一代**：电子管计算机
2. **第二代**：晶体管计算机
3. **第三代**：集成电路计算机
4. **第四代**：大规模集成电路计算机
5. **第五代**：人工智能计算机

### 关键考点

- 信息技术发展的五个阶段
- 各阶段的主要特征

### 记忆口诀

电子管，晶体管，集成大集人工智能

---

## 2.2 新技术发展

### 云计算

- 定义：基于互联网的计算方式
- 服务模式：IaaS、PaaS、SaaS
- 特点：按需服务、弹性扩展

### 大数据

- 定义：海量、高速、多样的数据集合
- 特征：Volume、Velocity、Variety、Value、Veracity
- 应用：数据挖掘、预测分析

### 人工智能

- 定义：使计算机模拟人类智能的技术
- 应用：机器学习、自然语言处理、计算机视觉

### 关键考点

- 云计算三种服务模式的区别
- 大数据的5V特征
- AI的主要应用领域

### 记忆口诀

云大物移智，新技促升级

---

## 2.3 信息化标准

### 标准化的意义

- 确保系统互操作性
- 提高系统可靠性
- 降低开发成本

### 主要标准

- ISO/IEC 27001：信息安全管理
- IEEE 802：网络标准
- SQL标准：数据库语言

### 关键考点

- 信息化标准的作用
- 常见的国际标准

### 记忆口诀

标准规范保质量，互操作降成本
