# 11.3 成本控制

## 定义

成本控制是指监控项目成本，管理成本偏差，确保项目在预算内完成的过程。

## 成本控制的目标

### 1. 监控成本绩效
- 跟踪实际成本支出
- 对比实际成本与成本基准

### 2. 管理成本偏差
- 识别成本偏差
- 分析偏差原因

### 3. 确保预算遵守
- 确保项目在预算内完成
- 避免成本超支

### 4. 预测项目成本
- 预测项目最终成本
- 及时采取纠正措施

## 成本控制方法

### 1. 挣值管理（EVM）
- **计划值（PV）**：计划完成工作的预算成本
- **挣值（EV）**：实际完成工作的预算成本
- **实际成本（AC）**：实际完成工作的实际成本

### 2. 偏差分析
- **成本偏差（CV）**：EV - AC
- **进度偏差（SV）**：EV - PV
- **成本绩效指数（CPI）**：EV / AC
- **进度绩效指数（SPI）**：EV / PV

### 3. 成本预测
- **完工估算（EAC）**：预测项目完工时的总成本
- **完工尚需估算（ETC）**：预测完成剩余工作所需的成本

## 成本控制流程

### 1. 监控成本支出
- 收集实际成本数据
- 记录成本支出情况

### 2. 对比成本基准
- 对比实际成本与成本基准
- 计算成本偏差

### 3. 分析偏差原因
- 分析偏差产生的原因
- 评估偏差的影响

### 4. 采取纠正措施
- 根据偏差情况采取措施
- 调整成本计划或资源分配

### 5. 更新成本基准
- 如果偏差较大，更新成本基准
- 获得相关方批准

## 挣值管理指标

### 成本偏差（CV）
- **公式**：CV = EV - AC
- **解读**：CV > 0 表示成本节约，CV < 0 表示成本超支

### 进度偏差（SV）
- **公式**：SV = EV - PV
- **解读**：SV > 0 表示进度提前，SV < 0 表示进度落后

### 成本绩效指数（CPI）
- **公式**：CPI = EV / AC
- **解读**：CPI > 1 表示成本绩效好，CPI < 1 表示成本绩效差

### 进度绩效指数（SPI）
- **公式**：SPI = EV / PV
- **解读**：SPI > 1 表示进度绩效好，SPI < 1 表示进度绩效差

## 成本控制的注意事项

### 1. 及时监控
- 定期监控成本支出
- 及时发现偏差

### 2. 分析根本原因
- 深入分析偏差原因
- 采取针对性措施

### 3. 协调其他目标
- 平衡成本、进度和质量
- 避免牺牲质量换取成本节约

## 关键考点

1. **挣值管理的指标**
2. **成本偏差的计算方法**
3. **成本控制流程**

## 记忆口诀

挣值分析偏差预测，成本控制三方法，CV SV CPI SPI要记清

## 典型例题

**例题**：成本绩效指数（CPI）大于1表示什么？
A. 成本超支
B. 成本节约
C. 进度提前
D. 进度落后

**答案**：B

**解析**：CPI = EV / AC，当CPI > 1时，说明挣值大于实际成本，即成本节约。
