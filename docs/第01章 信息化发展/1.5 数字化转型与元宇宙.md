# 1.5 数字化转型与元宇宙

## 一、元宇宙

### 定义

1. 元宇宙（Metaverse）是一大批技术的集成
2. 陈刚教授的定义：元宇宙是利用科技手段进行链接与创造的，与现实世界映射与交互的虚拟世界，具备新型社会体系的数字生活空间
3. 沈阳教授的定义：基于扩展现实技术AR提供沉浸式体验，以及数字孪生技术生成现实世界的镜像，通过区块链技术搭建经济体系，将虚拟世界与现实世界在经济系统、社交系统、身份系统上密切融合，并且允许每个用户进行内容生产和编辑
4. 左鹏飞：从时空性、真实性、独立性、连接性四个方面交叉定义

### 主要特征

1. 沉浸式体验——即时信息基础上的沉浸式体验
2. 虚拟身份——人们已经拥有大量的互联网账号，一个或若干个数字身份
3. 虚拟经济——这些活动需要一定的经济模式展开，即虚拟经济
4. 虚拟社会治理——需要一定的法律法规和规则的约束

### 发展演进

1. 元宇宙首先会在社交、娱乐和文化领域发展，形成虚拟"数字人"，逐步再向虚拟身份方向演进，形成"数字人生"，此时偏向个体用户需求
2. 三元空间——物理空间、社会空间、信息空间

### 三元空间定义

是建立在数字化转换、数字化升级基础上，进一步触及组织核心业务，以新建一种业务模式为目标的高层次转型

人类社会的三元空间：信息空间、物理空间、社会空间

【口诀：无色系】

## 二、数字化转型

### 驱动因素

1. 生产力飞升：第四次科技革命
   第一科学范式为经验范式
   第二科学范式为理论范式
   第三科学范式为模拟范式
   第四科学范式为数据密集型研究范式
2. 生产要素变化：数据是与土地、劳动力、资本和技术并列的主要生产要素
3. 信息传播效率突破：社会互联网新格局，社交网络信息传输具有永久性、无限性、即时性以及方向性的特征
4. 社会"智慧主体"规模：快速复制与智能
   社会的"智慧主体"已经不单纯是自然人，可是一个互联网账号、一台自动驾驶的汽车、一部智能手机，或工厂中的一套智能机器人

### 基本原理

1. 能力因子定义和数字化"封装"
   总结：将复杂业务解构为可量化、可调度的最小能力单元，形成【能力域—子域—项—分项】的层级结构，并通过【人员+技术+资源+数据+流程】的标准化封装，转化为数字化组件
2. 基于"互联网+"的调度和决策
   总结：将行业知识（如司机经验、交通规则）转化为算法模型，实现决策自动化，摆脱对个人经验的依赖
3. 转型控制
   不是指一个结果的表达，而是一个持续的过程

### 智慧转移

个体智慧（知识、技能和经验等）由"自然人个体"转移到组织智慧（计算机、信息系统等掌握的）

#### 1. 智慧数据（信息化的过程，信息系统规划、建设、运行过程）

内容：
1. 智慧结构化——明确了业务体系层面的内容
2. 知识模型化——定义业务活动的逻辑关系
3. 过程信息化——明确各执行操作系列要求
4. 数据平台化——实现了数据的采集、存储和共享

#### 2. 数据智慧（智慧化的过程，数据的开发利用和资源管理的过程）

内容：
1. 对象数字化——实现对各类对象的数字化表达
2. 孪生虚拟化——完成物理对象到信息空间的映射
3. 架构可视化——实现业务知识模型与经验沉淀的复用和创新
4. 计算智能化——实现多元条件下的调度和决策

补充：S&D模型就是基于DIKW模型，构筑了智慧-数据、数据-智慧两大过程的8个转化活动

### 持续迭代活动

1. 信息物理世界屏建设
先给现实中的每个东西（人、设备）建一个一模一样的虚拟模型，实时同步状态【建模】
2. 决策能力边际化部署
让第一线的设备和员工拥有"小脑筋"，能自己快速做一些现场的小决定，不用事事请示【给大脑】
3. 科学社会物理博弈机制构筑
建立一套"团队协作规则"，让所有虚拟模型和"小脑筋"能互相配合，像一个大团队一样，共同完成复杂任务【联成网】
4. 数字框架与信息调制
确保所有模型和大脑之间的信息传递是高清、无延迟、无错误的，这是所有智能化的基础【强信号】
