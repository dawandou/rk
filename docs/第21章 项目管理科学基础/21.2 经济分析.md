# 21.2 经济分析

## 定义

经济分析是指对项目进行经济评估，分析项目的成本和收益，为投资决策提供依据的方法。

## 经济分析的核心内容

### 1. 成本效益分析
- **定义**：比较项目成本和收益
- **应用**：评估项目可行性

### 2. 投资回报率（ROI）
- **定义**：项目收益与投资的比率
- **公式**：ROI = (收益 - 成本) / 成本 × 100%

### 3. 净现值（NPV）
- **定义**：项目未来现金流的现值
- **公式**：NPV = Σ(现金流 / (1 + r)^n)

### 4. 内部收益率（IRR）
- **定义**：项目净现值为零时的折现率
- **应用**：评估项目盈利能力

## 经济分析的步骤

### 1. 成本估算
- 估算项目总成本
- 包括直接成本和间接成本

### 2. 收益估算
- 估算项目收益
- 包括直接收益和间接收益

### 3. 指标计算
- 计算投资回报率、净现值、内部收益率
- 评估项目经济可行性

### 4. 敏感性分析
- 分析变量变化对结果的影响
- 评估项目风险

## 经济分析的方法

### 1. 静态分析
- **特点**：不考虑时间价值
- **方法**：投资回报率、回收期

### 2. 动态分析
- **特点**：考虑时间价值
- **方法**：净现值、内部收益率

## 经济分析的应用场景

### 1. 项目立项阶段
- 评估项目可行性
- 为决策提供依据

### 2. 项目选择阶段
- 比较不同项目方案
- 选择最优方案

### 3. 项目监控阶段
- 评估项目经济效益
- 调整项目策略

## 经济分析的注意事项

### 1. 考虑时间价值
- 资金具有时间价值
- 未来资金的价值低于现在

### 2. 全面考虑成本和收益
- 考虑所有成本和收益
- 避免遗漏

### 3. 敏感性分析
- 分析变量变化的影响
- 评估项目风险

## 关键考点

1. **经济分析方法**
2. **投资决策指标**
3. **经济分析的步骤**

## 记忆口诀

经济分析看效益，成本回报现值要算好，动态分析更准确

## 典型例题

**例题**：以下哪种经济分析方法考虑了时间价值？
A. 投资回报率
B. 回收期
C. 净现值
D. 成本效益比

**答案**：C

**解析**：净现值（NPV）考虑了资金的时间价值，将未来现金流折现到现在进行计算。投资回报率和回收期属于静态分析方法，不考虑时间价值。
