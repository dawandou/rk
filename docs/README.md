# 软考高项知识词典

欢迎来到软考高项知识词典！这是一个专为软考《信息系统项目管理师》考试打造的知识学习平台。

## 关于本网站

本网站提供全面的软考高项知识体系，包括：

- **知识体系**：涵盖24章核心知识点，从信息化发展到法律法规
- **高频考点**：重点标记考试高频考点，帮助快速复习
- **真题解析**：历年真题详细解析，掌握考试规律

## 网站结构

### 顶部导航
- **首页**：网站概览和快速入口
- **知识体系**：按章节浏览知识点
- **高频考点**：重点知识点汇总
- **真题解析**：历年真题详解

### 左侧导航
- 24章内容分类导航
- 支持折叠/展开章节
- 当前选中高亮显示

### 主内容区
- 本章概览
- 知识点详细内容
- 定义/解释
- 关键考点
- 记忆口诀
- 典型例题

## 学习建议

1. **按章节学习**：从第01章开始，循序渐进
2. **重点突破**：关注高频考点，强化记忆
3. **真题练习**：通过真题检验学习效果
4. **口诀记忆**：利用记忆口诀快速掌握知识点

## 技术支持

本网站基于 VuePress 构建，使用 Markdown 编写内容，支持全文搜索功能。
