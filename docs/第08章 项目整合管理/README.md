# 第08章 项目整合管理

## 本章概览

本章介绍项目整合管理的概念、项目章程和项目管理计划的制定，以及整体变更控制的方法。

**重点知识点：**
- 项目整合管理的内容
- 项目章程的编写
- 项目管理计划的组成
- 整体变更控制流程

---

## 8.1 项目章程

### 定义

项目章程是正式批准项目的文件，授权项目经理开展项目工作。

### 内容

- 项目目的和目标
- 项目范围描述
- 里程碑进度计划
- 预算摘要
- 项目经理任命

### 关键考点

- 项目章程的作用
- 项目章程的内容

### 记忆口诀

章程批准项目，授权经理开展工作

---

## 8.2 项目管理计划

### 定义

项目管理计划是指导项目执行、监控和收尾的综合性文件。

### 组成部分

- 范围管理计划
- 进度管理计划
- 成本管理计划
- 质量管理计划
- 风险管理计划

### 关键考点

- 项目管理计划的组成
- 各子计划的作用

### 记忆口诀

范围进度成本质量风险，计划组成要齐全

---

## 8.3 整体变更控制

### 定义

整体变更控制是指对项目变更进行识别、评估和管理的过程。

### 流程

- 变更请求提交
- 变更评估
- 变更审批
- 变更实施
- 变更验证

### 关键考点

- 变更控制流程
- 变更管理的重要性

### 记忆口诀

提交评估审批实施验证，变更控制五步骤
