# 第05章 信息系统工程

## 本章概览

本章介绍信息系统工程的概念、软件工程方法以及系统集成的相关知识。

**重点知识点：**
- 信息系统工程概述
- 软件工程方法
- 系统集成技术
- 项目管理在工程中的应用

---

## 5.1 工程概述

### 定义

信息系统工程是指运用工程化方法对信息系统进行规划、设计、开发和实施的过程。

### 工程特点

- 系统性
- 复杂性
- 长期性
- 风险性

### 关键考点

- 信息系统工程的特点
- 工程化方法的优势

### 记忆口诀

系统复杂长期风险，工程方法来保障

---

## 5.2 软件工程

### 定义

软件工程是指应用工程化方法进行软件的开发、维护和管理。

### 软件生命周期

- 需求分析
- 系统设计
- 编码实现
- 测试验证
- 运行维护

### 关键考点

- 软件生命周期各阶段
- 常用开发模型

### 记忆口诀

需设编测维，软件生命全周期

---

## 5.3 系统集成

### 定义

系统集成是指将各个独立的系统组件整合为一个统一的系统。

### 集成类型

- 硬件集成
- 软件集成
- 数据集成
- 网络集成

### 关键考点

- 系统集成的类型
- 集成方法和技术

### 记忆口诀

软硬数网，系统集成四大块
