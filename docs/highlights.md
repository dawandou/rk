# 高频考点

## 第01章 信息化发展

### 高频考点
1. **信息化的定义和特征**
   - 信息化是培养、发展以计算机为主的智能化工具为代表的新生产力
   - 特征：综合性、渗透性、创新性、带动性、全球性

2. **国家信息化战略**
   - 网络强国战略、大数据战略、"互联网+"行动计划
   - 战略目标：建设网络强国、数字中国

3. **信息系统的组成要素**
   - 人、机、软、数、流五大要素
   - 功能：输入、处理、输出、存储、控制

### 记忆口诀
人机软数流，输入处理存控制，生老病死全周期

---

## 第02章 信息技术发展

### 高频考点
1. **信息技术发展阶段**
   - 电子管→晶体管→集成电路→大规模集成电路→人工智能

2. **云计算服务模式**
   - IaaS：基础设施即服务
   - PaaS：平台即服务
   - SaaS：软件即服务

3. **大数据特征（5V）**
   - Volume（数据量大）、Velocity（处理速度快）
   - Variety（数据类型多样）、Value（价值密度低）、Veracity（数据真实性）

### 记忆口诀
云大物移智区块，新技引领数字化

## 第11章 项目成本管理

### 高频考点
1. **成本估算方法**
   - 类比估算、参数估算、自下而上估算、三点估算

2. **挣值管理指标**
   - CV = EV - AC（成本偏差）
   - CPI = EV / AC（成本绩效指数）
   - SV = EV - PV（进度偏差）
   - SPI = EV / PV（进度绩效指数）

3. **成本控制方法**
   - 挣值管理、偏差分析、成本预测

### 记忆口诀
挣值分析偏差预测，CV SV CPI SPI要记清
