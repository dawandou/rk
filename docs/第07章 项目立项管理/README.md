# 第07章 项目立项管理

## 本章概览

本章介绍项目立项管理的流程、可行性研究以及招投标管理的相关知识。

**重点知识点：**
- 项目立项流程
- 可行性研究内容
- 招投标管理流程
- 立项文档编写

---

## 7.1 立项流程

### 定义

项目立项流程是指从项目提出到项目批准的全过程。

### 流程步骤

- 项目建议
- 可行性研究
- 项目评估
- 项目审批

### 关键考点

- 立项流程的步骤
- 各步骤的主要任务

### 记忆口诀

建议研究评估审批，立项流程四步骤

---

## 7.2 可行性研究

### 定义

可行性研究是对项目的技术、经济、环境等方面进行全面分析，评估项目的可行性。

### 研究内容

- 技术可行性
- 经济可行性
- 社会可行性
- 风险评估

### 关键考点

- 可行性研究的内容
- 可行性研究报告的结构

### 记忆口诀

技术经济社会风险，可行性研究四方面

---

## 7.3 招投标管理

### 定义

招投标管理是指通过招标方式选择项目承包商的过程。

### 流程步骤

- 招标公告
- 资格预审
- 投标文件编制
- 开标评标
- 中标通知

### 关键考点

- 招投标流程
- 评标方法

### 记忆口诀

公告预审投标开标评标中标，招投标流程要记牢
