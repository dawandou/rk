# 第23章 组织通用管理

## 本章概览

本章介绍组织通用管理的概念、管理学基础以及人力资源和财务管理的方法。

**重点知识点：**
- 管理学基础
- 人力资源管理
- 财务管理
- 组织行为学

---

## 23.1 管理学基础

### 定义

管理学基础是指管理的基本原理和方法。

### 核心内容

- 管理职能
- 管理理论
- 管理方法

### 关键考点

- 管理职能
- 管理理论

### 记忆口诀

管理职能四方面，计划组织领导控制要做好

---

## 23.2 人力资源

### 定义

人力资源管理是指管理组织的人力资源，提高员工绩效的过程。

### 核心内容

- 招聘与选拔
- 培训与发展
- 绩效管理

### 关键考点

- 人力资源管理流程
- 绩效管理方法

### 记忆口诀

人力资源管人才，招聘培训绩效要管好

---

## 23.3 财务管理

### 定义

财务管理是指管理组织的财务资源，确保财务健康的过程。

### 核心内容

- 预算管理
- 成本控制
- 财务分析

### 关键考点

- 财务管理的内容
- 财务分析方法

### 记忆口诀

财务管理管资金，预算成本分析要做好
